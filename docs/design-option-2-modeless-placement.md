# 方案 2：模块库 + 免切换放置

> **状态：候选方案，尚未选定。** 与[方案 1：拼装模式](ue5-level-editor-mode-design.md)并列，由项目负责人后续选择。
> **目标引擎：** UE 5.7。方案未在引擎中验证，手感和实现成本要靠原型确认。
> **前提：** 模型注册信息由扫描工具根据名称和视觉识别生成，本方案视为已有。
> **表格版：** [design-option-2-plan.xlsx](design-option-2-plan.xlsx)

## 核心思路

把工具从“拼装模式”改成“模块库 + 免切换放置”，吸附优先靠模型包围盒计算，插槽只作可选增强。

地编同学不必理解模式和数据结构，打开模块库、拖进场景，模块就能贴合。

## 与方案 1 的差异

| 方案 1 | 方案 2 的调整 | 原因 |
|---|---|---|
| 先进入拼装模式再放置 | 平时不用切换模式，放置时自动接管，结束后恢复原状态 | 少一步操作，也少一种要记住的状态 |
| 插槽是核心吸附方式 | 以邻接吸附为主，有插槽时再优先使用 | 名称和视觉识别不一定能得出精确插槽 |
| 需要 `plug`、`target`、`types` 等规则 | 第一版不做 | 维护成本高，也不是使用门槛最低的方式 |
| 依赖数据里的尺寸和 pivot | 尺寸和 pivot 从模型实时读取 | 这些信息比识别结果更可靠 |
| 把注册信息当作完全正确 | 支持在模块库里修正，并保存为覆盖项 | 视觉识别难免出错，重新扫描时也不应冲掉人工修正 |

## 使用流程

1. **找模型：** 支持搜索、分类和尺寸筛选，并提供最近使用和收藏。也可以用吸管点击场景中的模型，定位到对应卡片。
2. **放置：** 把卡片拖进视口后，模型预览会自动贴合邻近模块或表面。开启连续放置后可以一直点放，按 `Esc` 退出。
3. **换款：** 放置时按 `[` 和 `]` 切换同类同尺寸模型，按 `R` 旋转。这两组按键只在放置时生效。
4. **替换：** 选中场景中的模型，再点击卡片上的“替换”，位置和旋转保持不变。这比删除后重新摆放快得多。
5. **整理：** 提供对齐、等距分布和沿街面对齐，也可以一键选中同款或同类模型。这些操作都能一次撤销。

## 吸附规则

优先级依次为：

1. **插槽：** 仅在数据中有插槽时使用。
2. **邻接：** 让包围盒的边或面贴合相邻模块，适合墙体、窗和门。
3. **表面：** 贴合光标下的表面，适合植物、灯具等不规则模型。
4. **网格：** 在当前平面内按步长对齐位置。
5. **自由：** 按住 `Ctrl` 临时关闭吸附（快捷键还需核对冲突）。

视口只显示当前吸附类型，加上绿色或蓝色的提示。设置只保留总开关和网格步长，其他参数放进“高级”。

## 注册数据

- **必需字段：** `id`、`asset_path`、`display_name`、`category`、`tags`。
- **可选字段：** `sockets`、`front_plane`、识别置信度。
- **低置信度或未分类：** 模型仍可正常使用，只在卡片上标记待确认。
- **人工修正：** 存到独立的覆盖文件，加载时优先使用。

## 沿街面对齐

点击基准模型的某个面，其他选中模型沿该面的法线移动并对齐。这样既能处理十字路口的不同朝向，也解决了单选时基准从哪里来的问题。

有 `front_plane` 时可以更精确，没有也能用；如果模型带招牌等凸出物，包围盒结果可能有偏差。

## 交付顺序（粗估）

以下工时未经实测。

| 阶段 | 内容 | 粗估工时 |
|---|---|---|
| 原型 | 验证拖入视口、实时预览吸附、松手生成、一次撤销 | 约 3 天 |
| 第一版 | 模块库、拖放、邻接/表面/网格吸附、替换、选中同款 | 3–4 周 |
| 第二版 | 连续放置、换款、吸管、对齐与分布、数据修正 | 2–3 周 |
| 后续 | 插槽增强、沿线批量排布、配方联动 | 按使用反馈决定 |

## 第一版验收

让地编同学用工具和现有方式各拼一段相同的街墙，比较耗时和后续手动修正的次数。
